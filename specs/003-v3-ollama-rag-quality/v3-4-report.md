## 交付内容

- 新增全局证据选择：从检索到的 Child 读取并去重 Parent，过滤低分结果、未就绪文档和明显不符的设备型号，再按问题相关性与检索分数排序。最终上下文受长度限制，证据保留来源文件、章节、页码与引用编号。
- 多问题 Agent 先收集证据，再由归并节点统一去重、选择、回答和执行原有答案评估；生产 Ollama 路径不再把某个 Agent 的第一段上下文或多段独立答案直接拼作最终答案。相同 Parent 在请求范围内复用读取结果。
- 上下文仅在超过配置的 Token 阈值时调用本地 Ollama 压缩；压缩请求要求逐字摘录相关片段，程序验证摘录确实来自原文。模型遗漏或给出无效摘录时，回退到可核对的原文摘录，不把未经核实的模型摘要当证据。
- 最终回答使用结构化输出与逐字引文校验，核对数字、单位和中文数字是否出现在引用中；保留来源、页码、章节。模型写错数值时仅在有单条短而完整的精确引文时回退显示原文，否则返回“信息不足”。证据为空或低相关度时不调用回答模型，也不编造答案。
- 对措辞相近、针对同一问题且单位相同的两条不同数值声明，先做保守的冲突检测；检测到冲突时直接列出双方原文和来源，说明无法确定唯一数值，避免小模型任选其一。
- 增加证据选择、压缩、来源校验、低相关度/无证据/冲突的自动化测试，以及隔离索引的真实 PDF + Ollama 验收脚本。
