### User Story 5 - 使用真实服务完成文档问答（P1）
管理员能登录工作台，上传可提取文本的文档，等待处理完成，连续提出两个明确问题，查看真实生成的答案、资料来源与执行过程，切页后仍能继续阅读，最后删除本轮测试文档并退出。

Independent Test：一份自建合成资料、两个完整事实问题各首次提交一次；保存原答与逐题对照，验证上传生命周期、连续两轮、来源、跨页、删除与退出。两个答案分别核对72小时和45天，但正确答案文件不传给被测系统。

- FR-014：联调通过真实服务和当前已配置模型完成，结果来自实际文档处理、检索和生成；不得以受控界面响应替代。
- FR-015：使用隔离资料库和临时测试账号，正式资料、配置、账号和历史失败保持；只删除本轮上传的文档。
- SC-006：登录、文档就绪、两次首次问答与来源、跨页保留、删除及退出均有可追溯真实记录；工程链路和答案事实正确性分别判定。
- SC-007：每题保存完整原答、正确答案、来源及可取得的用量和耗时；失败不改判，未运行明确列出，不自动改问或重试模型。

边界：最多两个问答请求，不重跑历史题集或修复016的四个质量问题；不升级依赖或改模型/提示。沿用当前模型配置。原A–D已交付，本轮E报告后暂停，等待用户验收。

## User Scenarios & Testing

### User Story 1 - 进入统一工作台 (Priority: P1)
管理员使用现有账号登录，查看真实服务与索引状态，通过桌面或移动导航进入问答台和知识库。
**Independent Test**: 登录成功/失败、防重入、移动Sheet焦点及健康状态；A原报告保留。B仅移除日志入口和旧路由。
**Acceptance Scenarios**:
1. 登录保持白底单列、水平居中并整体位于中上部，没有左侧宣传。
2. 保留token、密码显示、错误、autocomplete与现有认证语义。
3. 导航只有问答台和知识库；旧日志地址替换为问答地址；移动导航支持Escape与焦点返回。
4. 健康状态只依据有效响应，不推断模型位置，不因健康失败登出。

### User Story 2 - 连续对话与可读过程 (Priority: P1)
用户连续提问，逐轮阅读答案、来源、查询分析与工具活动。
**Independent Test**: 连续两轮、键盘/输入法、累计答案、折叠过程、来源原文、澄清、失败恢复、切页与退出隔离。
**Acceptance Scenarios**:
1. 发送后立即追加用户消息并清空输入，旧轮不清除；输入固定在工作区底部，消息独立滚动。靠近底部时跟随；向上阅读不被拉回。
2. Enter发送、Shift+Enter换行；组合输入或选字确认不发送；长按、双击及运行中重复提交被阻止。只接收非空且不超过2000字的输入。
3. 失败保留轮次与收到的部分内容，恢复原提交文字，不自动重试。运行中禁止发送和新会话。
4. 当前简短状态由真实事件驱动，不模拟思考进度；每轮过程默认折叠，工具开始与结果只在具有可靠身份时合并。
5. 答案支持基础Markdown及复制，来源位于对应答案下，完整Child/Parent和页码按需展开；不执行原始HTML或加载远程图片。
6. 澄清作为助手消息，默认直接发送补充，并保留继续补充/新问题/取消动作。失败pending与清除时机以服务端为准。
7. 切到知识库不断流、不丢会话；刷新/新会话/退出清空内存。退出终止前端读取并阻止迟到事件污染新会话。
8. 累计答案替换对应轮正文与来源，不重复拼接、不跨轮混合；技术细节保留真实/回放和实际/估算标识，不展示在线核验卡。

### User Story 3 - 管理 PDF 文档 (Priority: P1，C已交付)
沿用原规格：单PDF选择/拖入、名称与状态交集过滤、真实生命周期与父子分块数、删除确认及失败反馈；不新增批量、OCR或排序。
**Independent Test**: 单文件/多文件拒绝、处理轮询、过滤、删除取消/成功/失败。

### User Story 4 - 前端日志退出主流程 (Priority: P2，B)
**Independent Test**: 桌面/移动导航无日志、旧地址转问答、页面无日志请求；后端日志代码和数据指纹保持。
**Acceptance Scenarios**: 移除前端日志页面与消费代码；后台日志、诊断API和历史记录保留，不清除任何后台数据。

### Edge Cases
390px窄屏、200%缩放、输入法组合与229键码、超长标识/表格、失败与中断、退出后迟到事件、并行同名工具、缺失调用ID、空来源、剪贴板不可用、存储异常和减少动态效果。

## Requirements

### Functional Requirements
- **FR-001**: 登录/问答/知识库统一浅色视觉、排版、图标、按钮、表单及状态语言。
- **FR-002**: 保留已交付登录效果、认证与可访问交互。
- **FR-003**: 两项主导航、桌面折叠与移动Sheet、真实健康状态和退出保持可用。
- **FR-004**: 连续对话按轮保存正文、来源、原文、过程及错误；累计答案不得重复拼接或跨轮混合。
- **FR-005**: 澄清四类动作、失败pending、请求/线程标识、切页不断流与退出隔离保持现有语义。
- **FR-006**: 基础Markdown和原文复制，禁用HTML和远程图片，复制失败反馈。
- **FR-007**: 简短状态来自真实事件；过程默认折叠，可靠ID合并调用，保留实时/回放和估算标识；无在线核验或正确率承诺。
- **FR-008**: C阶段文档管理保留单PDF、过滤、删除确认与全部既有状态。
- **FR-009**: 移除前端日志与请求，旧日志地址替换为问答；后台日志及诊断保持。
- **FR-010**: 目标视口、200%缩放、键盘、焦点和减少动态效果可用，内容不遮挡输入。
- **FR-011**: 同职责单库，组件源码可控，新增直接依赖精确固定、有使用点和审计。
- **FR-012**: 保护已有修改、配置、正式数据、历史报告及真实质量失败；单阶段报告后暂停。
- **FR-013**: Enter发送、Shift+Enter换行、输入法确认不发送；防重入、非空与2000字限制、失败文字恢复。

### Key Entities
登录与布局状态、当前会话、独立轮次、累计答案/来源/原文、活动调用/阶段、用量、澄清待办与终态。

## Success Criteria
- **SC-001**: B问答/导航与C知识库分别在390/768/1440/1920px、200%缩放、键盘与减少动态效果下核对，无页面横向溢出；D已完成三页最终矩阵。CSS内容放大允许垂直滚动访问输入，等效浏览器200%下输入保留在视口内。
- **SC-002**: 键盘/输入法/防重入、两轮问答、失败/澄清、折叠/工具关联、日志移除与路由均有可定位验证。
- **SC-003**: 跨轮混入、重复累计文本、退出迟到回填均为零；切页不断流。
- **SC-004**: 同职责重复直接库、未使用新增直接库、重复React版本均为零。
- **SC-005**: 真实/模拟/未测分别报告；本轮只实施用户获准的D。A/B/C/D工程结果不代表真实后端或模型问答质量验收。

## Assumptions
当前会话仅内存，不新增历史列表、永久保存、多会话、后台功能。模型质量沿用016报告，不调用真实模型或操作正式知识库。只启动隔离浏览器验证所需前端，不启动/重启后端。无真实生成中止承诺：退出只终止前端读取。
