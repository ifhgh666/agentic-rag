## 一、校准题干与必答范围

| 题号 | 候选版核心要求 | 不再强制的内容／另行检验 |
|---|---|---|
| Q1 | 输入电源、接地、负载连接、电压和频率处于允许范围、急停复位、保护灯熄灭、面板无故障 | 合格万用表及量程具体数字为有来源的补充；精确区间保留在 Q6 |
| Q2 | 输出电流超过 16 A 且持续 100 ms | 立即断开主回路是保护动作，题干没有问，改为可选 |
| Q3／Q15 | 断开负载 → 等待完全放电 → 查短路 → 确认正常 → 清除告警 → 重新上电 | 安全前置与顺序不减；正文优先于第 4 页简化 FAQ |
| Q4／Q10 | 默认保留三年 | 先进先出为可选；删除策略由 Q23 直接提问 |
| Q5／Q7 | 每六个月维护一次 | 已明确对象时不要求正文再次输出 PX-200；Q7 仍要核验入口消解对象正确 |
| Q8 | 同时回答三年保留与六个月维护 | 删除策略不附加为必答；双问题真实挑战保留 |
| Q14 | 给出超过 16 A／100 ms，并语义纠正错误前提 | 删除“纠正用户给出的错误数值”这种元话语匹配要求，行为另列；保护动作可选 |

可选事实也保存来源；不答不扣完整性，答错仍是事实错误。恢复操作不得把必要步骤改成可选。中文／阿拉伯数字、准确单位换算、同义词和排列方式可以等价；严格大小关系、否定范围、设备对象不能被归一化成另一含义。

例如“输出电流大于 16 安并持续 0.1 秒”可表达 Q2 的核心条件；“达到 16 A 就触发”不行。“不是 15 A／50 ms，正确是超过 16 A 且持续 100 ms”可以在否定中提及错误数字，不能只因这些数字出现就判作肯定事实错误。

Q7 的合成前置改为只有一条用户声明设备主题，移除预填助手标准答案。其他带历史的种子题同样明确标为合成前提。标准答案、量规、正负例不进入问答模型或检索上下文。

## 二、澄清流程先检查前置，再判断分支

Q9–Q12 保留原始首轮“它发生过流后如何恢复？”和空历史，依照现有提示词与规格仍预期先澄清。不会因知识库只有 PX-200，就修改测试政策允许模型擅自补对象。

共享入口 E01 必须实际满足：状态为澄清、`phase=awaiting_clarification`、保留原待办、没有检索或普通答案。任一不满足时，端到端场景不通过，但后续轮次记 `blocked_by_prerequisite／not_tested`，不把补充／新题／取消／不确定能力全部归因为失败。

各分支仍用独立线程，不复制一个分支的实际结果冒充另一个。报告可归并共享入口根因，但保留每次实际记录。检索问题示例按对象、意图、约束核验，不以逐字相同作语义验收标准。

另列 S01–S08 合成待办起点，直接表达合法 ThreadState 的待办字段，不从普通消息角色猜测待办。只允许隔离离线测试，不能注入用户真实会话。它们能用于隔离分支，但不能证明真实入口工作正常。

**尚未实现**：现有采集器不执行前置阻塞、不加载这些状态夹具，也没有完成上述语义判定／组级汇总。保留旧脚本不改，本轮只交付规约；T032 单独列为后续任务。不能直接使用旧 `flow_checks` 宣称新版流程验收完成。

## 四、对旧报告结论的校正

保留 [2026-10-07 原报告](formal-ragas-report.md)、[观察数据](formal-ragas-observation.json)、原始采集和 Judge JSON，不改旧分数、不重新贴标签为新版结果。

- **Q2**：原报告按旧批准范围记“未输出立即断开主回路”，并据此断言裁判漏判。这一归因过强：题干只问触发阈值，正确给出 16 A／100 ms 已覆盖核心问题。单凭未复述设备动作，不能证明阈值回答错或 Judge 漏判。旧记录保留，新解释以本报告为准；这也不等于给实际回答补一条人工签收。
- **Q1／Q7**：字面提示不代表语义错误；Q7 不重复型号也不直接判漏答。保留实际回答和待复核状态，不自动补通过。
- **Q9–Q12**：首轮直接回答、未建立待办仍是合法的入口问题；原后续结果没有满足待办前提，不能证明四个分支能力失败或成功。Q9 的五项指标错误也不是五道题答错。
- **Q8／Q14**：上下文有核心答案却最终回退，这些真正的回答问题没有被校准消除。轨迹分别记录 `unsupported_number` 和 `unsupported_numeric_fact`；被拒生成正文未保存，不能确定具体触发数值。
- **Q13**：最终未编造不等于模型主动理解无答案；原轨迹 `invalid_json` 应记作技术回退，不能当语义拒答验收通过。
- **评估运行**：75 条指标中 22 项评分、33 项错误、20 项不适用仍是原批事实。事实指标 22/50 为评分覆盖率，不是准确率。超时、预算不足、同一链路失败分开统计，不补 0。回答与裁判同为 4B 模型，旧高分不能代替安全步骤人审。

新版参考答案有变化，旧分数不能直接作为新版成绩，未经新审核、配置和预算批准不重跑。本轮没有追溯宣称 V3／V4 全部验收通过。
