- 使用当前业务 Graph、已有 Dense 模型和默认 BM25 真实词表，在正式索引的只读隔离快照上运行。不是工作台 UI 点击验收，也不是合成证据冒烟。

- 对超时、结构错误及预算耗尽保留错误/null，不补零分；分项结果不能替代人工安全步骤核对。
