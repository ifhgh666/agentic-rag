## 4. 验证器和审核闸门

验证内容包括：严格题型及字段、题号唯一、文档 UUID／SHA-256／题集版本一致、PDF 页数、引文所在页、必答事实列表、有序安全步骤、无答案全篇核对记录，以及逐轮动作与待办状态约束。

正式准入要求顶层题集和**全部题目**已审核、每题有人工审核者、带时区的审核时间及 `review_kind=human`，并且来源检查通过。任一草案或失配会拒绝整个题集；不会跳过失败题后仍声称全量通过。审核记录字段是人工确认的登记，不是脚本能验证的身份认证，自动执行者不能自行冒填。

当前普通检查结果：

```json
{
  "valid": true,
  "formal_ready": false,
  "dataset_version": "candidate-1.0",
  "case_count": 15,
  "quotes_checked": 26,
  "quotes_matched": 26,
  "eligible_case_ids": [],
  "ragas_case_ids": []
}
```

未审核题为 Q1～Q15。`source_checks_passed` 只表示该题的格式／来源检查没有报错，不能等同于人工认可、语义正确或模型回答通过。

验证器只核对 PDF 本体。现有索引清单没有 PDF SHA-256 绑定字段，因此本报告**不声称向量内容与文档指纹的一致性已经得到证明**；后续真实评估还需登记并核对实际索引版本与上下文。
