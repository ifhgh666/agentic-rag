## 3. 三项已知问题的固定复现

| 样例 | 当前行为与证据 | 期望行为／后续阶段 |
|---|---|---|
| 明确型号被误澄清 | `ConversationMemory.prepare("PX-200该如何维护？")` 在无历史时因“该”命中代词正则而 `question_is_clear=False`；对应 xfail 用例稳定复现 | 明确型号不应仅因“该”被拦下；阶段 B 用一次结构化分析判断 |
| 待澄清时用户换题 | 待办“过流保护后如何恢复？”后输入“运行记录默认保留多久？”，当前 `prepare` 直接生成“原问题＋补充信息”且判清楚；对应 xfail 用例稳定复现 | 将新题与补充区分，不能拼接；阶段 B 修复 |
| 漏安全步骤仍获高分 | 证据包含“断开负载、等待完全放电”，回答只含“检查负载、清告警、重启”时，当前 `AnswerEvaluator` 仍给 `completeness=78`，问题文本出现在上下文时 `overall=84`；对应 xfail 用例稳定复现 | 阶段 D 移除固定可信度，未核验完整性不得称完整；旧 V3 后续计划仍需修复实际生成答案 |

特别注意：PDF 第 4 页“推荐问答测试集”的 Q3 参考短答只写“检查负载、清告警、重新启动”，**省略**第 3 页故障处理正文的“先断开负载、等待设备完全放电”。因此草案 Q3 以第 3 页完整故障流程为准，并把第 4 页的简表列为“容易误导生成器的简化资料”，不能用简表覆盖安全前置步骤。

## 4. 五题草案摘要

| 题目 | 草案必答点 | 原文页 | 状态 |
|---|---|---|---|
| Q1 上电前检查 | 输入电源/接地/负载连接；198–242 V、49–51 Hz；急停复位、保护灯熄灭、无面板故障码 | 第 2 页 | `draft` |
| Q2 过流阈值 | **超过** 16 A 且持续 100 ms，不是“达到 16 A 立即触发” | 第 3 页 | `draft` |
| Q3 过流恢复 | 先断开负载 → 完全放电 → 查负载端短路 → 确认正常 → 清告警 → 重走上电流程 | 第 3 页 | `draft` |
| Q4 记录保留 | 默认三年；超期先进先出删除 | 第 3 页 | `draft` |
| Q5 例行维护 | 每六个月一次 | 第 3 页 | `draft` |

这些题暂不填写 `reviewer/reviewed_at`，不会冒称用户已审批。阶段 C 要扩展为至少 15 题、逐题人工复核并建立只读验证器；此时才可能形成正式版题集。真实业务 PDF 不在此次题集中。
