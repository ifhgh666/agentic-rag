# Feature Specification: 集中提示词与可审阅的问题改写规则

**Feature Branch**: 沿用 `codex/model-driven-agent-loop`，不创建或切换分支。
**Created**: 2026-10-12
**Status**: 2026-10-13：B工程交付完成，11提示函数全部按需接入，入口独立schema与缓存隔离保持；12项接入检查、15项等价场景及566项后端工程回归通过。20项工程任务完成，真实质量未测，C取消。见[阶段B报告](phase-b-report.md)，报告后暂停，等待用户验收。
**Input**: 用户要求先写计划，像GiovanniPasq/agentic-rag-for-dummies一样单独维护 `prompt.py`，需要提示词时调用函数，内容参考该项目，最终由用户检查函数。

## User Scenarios & Testing

### User Story 1 - 在一处审阅提示规则（Priority: P1）

用户能在一个独立位置检查各节点提示词，尤其能直接检查问题改写函数全文和允许改写的范围。

**Why this priority**: 避免提示词散落在业务逻辑中，用户能确认模型收到的规则符合设计。
**Independent Test**: 打开函数全文，核对职责、规则及调用映射；尚未接入运行时也可独立交付。
**Acceptance Scenarios**:

1. 提示词集中后，各固定提示有明确名称、职责与消费位置，业务按需取得文本。
2. 模块初版交付时提供实际函数位置、完整返回文本和参考差异，该阶段报告后等待用户审阅再推进下一阶段。
3. 参考项目格式与本项目不同时，保留本项目证据、引文及结构契约，不复制不兼容的输出要求。

### User Story 2 - 按用户规则整理问题（Priority: P1）

完整单问保持原句；缺少指代对象时只补必要对象或引用场景；多个独立需求才拆分，最多三个。未解决的指代需要澄清，所求答案不是用户必须提供的信息。

**Why this priority**: 对应006误澄清、型号/数字改错及共享条件缺失，不能靠无关改写改变用户问题。
**Independent Test**: 检查函数规则，并用固定问题及冻结历史分别验证完整问、指代、拆分和容量行为。
**Acceptance Scenarios**:

1. 型号、数值、条件及目标完整时原句保留，不反问保护阈值或恢复答案。
2. 有“它”“这个设备”等指代且历史唯一时只补必要信息；无法确定所指对象时只问缺失指代。
3. 两项或三项独立需求可拆分；相关子问保留共享型号和场景，不新增数字或发生事实。
4. 条件多但只有一个目标时，不因句子长或有“如果”就拆分；依赖需求无法独立表达时可以整体保留。
5. 四项无法在三问内保留时请求选择最多三项。这是容量澄清，不能删需求，也不是“不知道答案”。
6. 比较目标保留于原题及最终回答，不为两项已检索事实机械增加第三路比较检索。

### User Story 3 - 迁移可追溯且结果诚实（Priority: P2）

实际调用与用户检查的文本一致，旧缓存不能掩盖新规则；记录工程证据，真实模型质量保持未验证。

**Why this priority**: 避免函数已改却仍使用旧文本，或以文件重构宣称模型质量修复。
**Independent Test**: 用隔离工程检查核对调用点、版本、缓存和源文件指纹，交付实际函数及对应检查记录。
**Acceptance Scenarios**:

1. 修改规则后同一问题不复用旧规则缓存；其他行为等价迁移的调用预算与状态不变。
2. 继续、新题、取消依旧由明确动作适配；提示函数不调用模型、不决定检索或读写会话。
3. B报告记录函数版本、源码指纹、工程命令与结果；旧首答失败保持，不以工程检查宣称真实模型已修复。

### User Story 4 - 输出结构单独定义并直接使用（Priority: P1）

用户只需在独立结构定义处检查三个字段，改写提示只描述业务规则；模型调用直接使用该定义约束生成并取得结构化结果。

**Why this priority**: 让返回结构可独立审阅并在生成时使用，减少重复格式维护。
**Independent Test**: 用隔离模型和传输替身检查结构定义随请求发送、结果可按字段读取、错误不会变成成功；不代表真实改写质量。
**Acceptance Scenarios**:

1. 三个字段、类型、必填性和最多三问的结构限制由独立定义维护，提示中不重复字段格式或JSON示例。
2. 调用实际绑定该结构，清楚和待澄清结果均可直接读取；原始返回和用量仍可审计。
3. 不支持绑定、无效字段、互相矛盾的清晰度状态或超时均只尝试一次，保留现有失败原因和动作隔离。
4. 提示或结构定义改变后，不复用旧入口缓存；其余节点行为和真实失败记录保持原状。

### Edge Cases

- 陌生但明确的型号/术语仍可检索，不自行纠错或展开缩写。
- 历史40 ms不能覆盖当前400 ms；“如果触发”不变“已触发”。
- 恢复操作与阈值应检索，不向用户索要这些答案。
- 普通空格变化按用户已有许可审阅，不新增空格/数字运行时语义检测。
- 单问也可需要指代补全，不由程序按问题数量强制恢复原句。
- 工具原生/兼容协议、摘要长度及旧兼容调用取得适用提示，但不重新启用旧路径。
- 模型或接口不支持结构化生成时报告现有失败，不静默退回普通生成、不重试或切换云端。

## Requirements

### Functional Requirements

- **FR-001**: 固定提示词有可读、可审阅的集中来源，按职责取得文本，不在消费点复制完整规则。
- **FR-002**: 只允许必要指代补全和独立需求拆分；完整单问保持原句，不主动润色。
- **FR-003**: 指代无法由上下文确定时澄清；对象与目标明确时，不因不知道答案要求补充。
- **FR-004**: 最多三问且保留全部需求、共享条件和依赖；超容量请求选择，不静默删除或输出第四问。
- **FR-005**: 型号、数字、单位、文件、否定、条件及比较保真，不添加事实；不增加入口语义阻断或强制恢复原句。
- **FR-006**: 参考项目的职责分段和最少上下文思路；本项目输出、引用、工具、动作、预算、期限和保密契约继续成立。
- **FR-007**: 用户能检查实际改写函数全文、调用映射及差异，审阅后的阶段再接入调用。
- **FR-008**: 接入新规则时隔离旧改写缓存，工程交付记录包含函数源码及版本指纹；本计划不修改真实采集器。
- **FR-009**: 非入口提示只做行为等价迁移，不改检索循环、修正次数或摘要保真；固定修正/汇总指令也登记集中来源。
- **FR-010**: 只做必要工程验证并如实报告，真实模型质量未验证；旧首答及失败保留，不实施17题真实批次。
- **FR-011**: 规划不自动授权实施；仅执行用户明确指定阶段，保留模型、数据、配置和旧失败，每个获准阶段报告后暂停。用户已授权A、入口结构化补充及B，工程交付完成；报告后暂停。
- **FR-012**: 输出结构独立维护，只含is_clear、questions、clarification_needed，禁止额外字段；改写提示不重复结构说明。
- **FR-013**: 入口请求直接绑定输出结构，消费者按结构化字段读取；保留首答和用量，不能用输出后校验冒充生成约束。
- **FR-014**: 结构化调用仍服从一次入口调用、窗口、预算、期限及隐私边界；不支持或失败时不换模式、重试或切换提供方。

### Key Entities

- 提示词定义：职责、正文、取得函数、版本及参考来源。
- 调用映射：消费位置、协议/参数、上下文来源及迁移方式。
- 审阅记录：完整返回文本、差异及实施阶段。
- 工程交付记录：函数版本/源码、检查命令/退出状态、用户审阅位置及真实未测说明。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 已登记固定提示和修正/汇总指令100%能追溯到集中定义及消费位置，没有未登记重复长提示。
- **SC-002**: 用户可在一个入口查看完整改写规则；调用实际使用该文本，旧缓存不替代新结果。
- **SC-003**: 完整问、指代、条件、容量、比较逐项核对；真实结果未达预期时不宣布质量通过。
- **SC-004**: 必要工程检查通过，调用次数、动作隔离、预算、期限和隐私不退化，模拟不替代真实质量。
- **SC-005**: A交付函数全文，B交付实际调用、缓存版本及必要工程检查证据；计划内真实模型调用为零，不宣称旧真实失败已修复。
- **SC-006**: 数据、配置和历史失败全部保留，每阶段有报告与停止点；规划不自动启动实现。
- **SC-007**: 隔离检查覆盖两种状态、实际请求绑定、错误/超时、缓存和原始用量；结构与提示可分别审阅，真实质量未验证。

## Assumptions

- 集中范围为RAG固定提示及修正指令，先审阅改写函数，其他提示行为等价迁移。工具schema、UI/失败文案、动态问题/历史/证据正文由原模块构建。
- 使用中文职责分段，不照搬上游的一般性重写权限或Markdown答案格式。
- 本计划不下载/替换模型。2026-10-13用户要求授权入口结构化补充，替代原“不改变调用方式”限制；其他节点不扩大迁移。
- 用户已取消阶段C，本计划结束于B工程交付，不运行真实入口题集；006及005的历史质量状态不变。
