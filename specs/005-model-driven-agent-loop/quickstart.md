## 3. 必须证明模型真的决定动作

脚本提供者保持问题、工具结果不变，只改变模型输出，验证实际轨迹改变：

1. 小于240字但充分：模型回答，不读Parent。
2. 大于240字但缺恢复步骤：模型请求补搜或Parent。
3. 非空结果但缺持续时间：模型换查询，程序不宣布证据够。
4. 空结果：模型可换查询或给具体缺口，程序不自动造新查询。
5. 同批多工具：每条返回按tool_call_id合并，单项失败不丢其他结果。
6. 模型未检索就宣称无资料/无来源作答：反馈协议问题，由模型选择工具，程序不代发。
7. 相同查询复用缓存、预算争用、未知Parent、超时与取消：来源明确，调用不越界，不退旧规则。

每条工具事件追到decision_id和真实model_call_id；fake只证明路由，不证明本机模型能力。
