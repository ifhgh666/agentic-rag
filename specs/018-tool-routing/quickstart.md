# 阶段 A 验证

在仓库根目录用 `python -X utf8 output/reference016/phase-a/run.py <新标签>` 运行现有隔离回归，关注路由、会话及 SSE 契约。在 `frontend` 运行 `npm.cmd test` 和 `npm.cmd run build`。Windows 临时文件权限受限时将构建进程的 TEMP/TMP 指向工作区内的临时目录。

- 用脚本模型验证“你好”显示中文普通回复，调用顺序为分流、直接回答，且无检索与澄清。
- 验证明确文档问题经过分流、改写、研究与聚合，来源来自工具记录。
- 验证模糊文档请求先澄清，补充后检索，显式新问题独立分流，取消不调用模型。
- 验证分流异常时无工具调用，同一会话可发起下一条消息。

真实模型使用普通问候、明确文档问题及澄清续答单独验收，遵守现有运行授权和隔离资料边界。
