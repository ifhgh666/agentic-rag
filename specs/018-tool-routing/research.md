# 调研：工具需求与查询充分性

- 决策采用独立的布尔结构化输出。现有兼容模型及 Ollama 已支持 `with_structured_output`，模型分流仅返回是否需要知识库。比较过在同一次响应中同时改写及分流，独立节点可以确保直接回复路径不执行检索分析。
- 直接回复沿用常规模型调用和既有答案 SSE，模型只读取对话上下文。已有的会话摘要和近期历史仍用于后续消息。
- 已进入待补充的请求先前已经选择知识库。沿用 checkpoint 的补充路由和取消，显式开始新问题时重做分流。
- 原参考图可作为研究分支的对照，分流和充分性指令是本功能新行为。
- 调用链核对确认 HTTP 层没有全局索引就绪门槛。分流放在历史整理前，因为整理在长会话中也会调用模型。直接回答沿用 LangGraph 消息流，结构化分流输出只写布尔状态。
