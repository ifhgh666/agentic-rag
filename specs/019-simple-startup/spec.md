# Feature Specification: 简化本地启动

**Created** 2026-11-14

**Status** 阶段 A 已实现并完成隔离启动验证。见[阶段报告](phase-a-report.md)。

## User Scenarios & Testing

### User Story 1 - 一条命令打开文脉（P1）

模型接口配置完成后，从仓库根目录运行一条命令即可启动工作台。首次运行会准备依赖和嵌入资源，之后复用已有环境。

1. 首次克隆时可以通过示例配置接入 OpenAI 兼容模型，无需安装或下载 Ollama 模型。
2. 已配置模型的工作区运行同一命令即可启动。已有模型和知识库配置保持可用。

### User Story 2 - 使用固定演示账号（P1）

通过本地启动器运行时，用用户名 `admin` 和密码 `123456` 登录。后端自动设置登录验证所需参数，用户无需生成密码哈希或 JWT 密钥。

### Edge Cases

- 缺少模型配置时给出具体字段，保留已经存在的配置文件。
- 端口被占用或启动失败时给出错误，并回收本次已启动的进程。
- 停止启动器会结束本次前后端进程。

## Requirements

- **FR-001** 快速开始采用 OpenAI 兼容接口，不要求下载 Ollama；显式配置的既有模型仍可使用。
- **FR-002** 启动器准备依赖和 Dense 缓存并启动前后端，仅绑定本机。
- **FR-003** 固定演示账号只在本机启动器启用，使用现有密码哈希校验和会话机制；普通启动入口继续使用已配置的凭据。
- **FR-004** 只有配置文件不存在时才初始化它，现有 API 密钥、数据及模型配置不被覆盖。

## Success Criteria

- **SC-001** 配置就绪后，一条命令能启动前后端。
- **SC-002** 固定账号能登录并访问受保护的文档列表，错误密码被拒绝。
- **SC-003** README 的快速开始省去 Ollama 下载和人工生成登录参数，并说明首次所需的模型接口设置。

## Assumptions

- 主入口使用 Python 3.11+ 和 Node.js 22+。首次安装依赖或缓存缺失时需下载资源。
- 鉴权和聊天公开接口保持原契约，部署模式不在本阶段范围。
